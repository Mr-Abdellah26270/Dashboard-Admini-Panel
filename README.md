# DashMaster

لوحة تحكم متقدمة (Dashboard Admin Panel) تدعم تعدد اللغات والاتجاهات، تصميم عصري، وميزات ديناميكية متكاملة.

## الميزات الرئيسية
- **واجهة تفاعلية حديثة** مع دعم Theme فاتح/داكن.
- **الشريط الجانبي والشريط العلوي** يغيران الاتجاه (يمين/يسار) تلقائياً بناءً على اللغة.
- **دعم كامل لتعدد اللغات**: (عربي، إنجليزي، فرنسي) مع ملفات ترجمة منفصلة وسهلة التعديل (locales/).
- **Skeleton Loading** عند تحميل البيانات لضمان تجربة سلسة.
- **نظام إشعارات ديناميكي** (يمكن الربط مع أي API لاحقاً).
- **نماذج بواجهات تحقق فوري ورسائل خطأ مرئية**.
- **تصدير تقارير إلى CSV، PDF، Excel**.
- **قوائم ديناميكية للمشاريع، المستخدمين، والمنتجات** (قابلة للتوسعة).
- **دعم الوصول وكفاءة استخدا�� عبر لوحة المفاتيح**.

## البدء والتشغيل

1. **فك الضغط أو نسخ الملفات إلى مجلد المشروع.**
2. **شغل الملف `index.html` مباشرة في متصفح حديث.**

لا يحتاج المشروع لأي باك-إند أو تشغيل سيرفر، وكل الوظائف مبنية على جافاسكريبت وواجهات API مجانية.

## بنية المشروع
```
Dashboard Admini Panel/
├── index.html           # الصفحة الرئيسية
├── css/
│   └── style.css        # أنماط متكاملة ودعم RTL/LTR
├── js/
│   ├── main.js          # ديناميكية الواجهة والمنطق
│   └── i18n.js          # محرك الترجمة والتبديل بين اللغات
├── locales/
│   ├── ar.json          # ترجمة عربية
│   ├── en.json          # ترجمة إنجليزية
│   └── fr.json          # ترجمة فرنسية
├── icons/
│   └── ...              # رموز ودعم الأيقونات
└── README.md            # هذا الملف
```

## التخصيص
- لإضافة أو تعديل لغة، عدل ملفات `locales/<language>.json` أو أضف ملف جديد بنفس البنية.
- لتغيير الألوان أو الشعارات، يمكنك تعديل CSS أو الأيقونات في رأس index.html.
- يمكن ربط الإشعارات والبيانات حقيقة بواسطتك مع أي API بسهولة عبر تحديث الدوال في main.js.

## المتطلبات
- أي متصفح حديث يدعم ES6 (كروم/فايرفوكس/إيدج/سفاري/أوبرا).
